# Часть I. Визуальное решение

## Главная метафора

Лендинг построен на **гибриде warm dark + warm cream + warm amber**:

> Основной фон — warm dark (тёплый низкий свет в подвале).  
> Карточки и текстовые блоки — warm cream (бумажная страница под лампой).  
> Финальный экран — warm amber (свет лампы крупным планом).

Метафора: тёмная комната с тёплым низким светом, в ней на столе — *открытая бумажная книга*. Книга яркая, остальное приглушённое. На последнем кадре — свет лампы заливает экран целиком.

## Перевод эмоций в дизайн

| Эмоция | Перевод |
|--------|---------|
| Тёплый низкий свет в подвале | Warm dark фон, ничего неонового |
| Открытая книга на столе | Карточки и текст-блоки в warm cream |
| Тихий разговор | Низкая визуальная громкость |
| Книга, проектор, инсталляция, лампа | Слои: фон → проекция → текст → акцент |
| Поздний вечер | Низкий контраст, точечные тёплые highlights |
| Подпольная встреча | Никакой festival-маркетинг-эстетики |

## Палитра

### CSS переменные

```css
:root {
  /* Фон */
  --color-bg-dark:     #16140F;  /* warm dark, основной */
  --color-surface:     #1F1B14;  /* на полтона светлее, для карточек на тёмном */
  
  /* Бумага */
  --color-bg-light:    #ECE3D0;  /* warm cream, страница под лампой */
  
  /* Акцент — единственный */
  --color-accent:      #C89A3D;  /* амбер, как свет лампы */
  
  /* Тексты */
  --color-muted:       #9A9080;  /* приглушённый бежевый для подписей */
}
```

### Принципы

- **Один акцент.** Только амбер `#C89A3D`. Никакого второго акцентного цвета.
- **Никакого чисто чёрного и чисто белого.** `#000`/`#FFF` исключены — всё имеет тёплый подтон.
- **Холодные тона запрещены.** Никаких синих/фиолетовых неонов, никакого SaaS-голубого.
- **Низкий контраст** между фонами и приглушёнными текстами. Высокий контраст — только в крупных заголовках и кнопках.

## Типографика

Сайт намеренно держит **высоко-низовой контраст** двух шрифтов:

- **Display** — `Cormorant Garamond Italic` — elegant antique serif, отсылка к ренессансной/античной книжной культуре. Курсив добавляет энергию и движение, чтобы заголовки не казались надгробными.
- **Body / labels / mono** — `JetBrains Mono` — современный технический моноширник. Даёт ассоциацию с программированием, формулами, математикой; визуально ритмизует длинные тексты в регулярную сетку.

**Идея:** античность встречает современную математику. Cormorant говорит «это старая, важная, красивая мысль», JetBrains Mono говорит «и одновременно это современное вычисление». Концепция фрактала — мост между этими двумя мирами.

### Типографика как объект

В двух местах сайта типографика используется не как текст, а как визуальный объект:

1. **About — гигантская «50»** — Cormorant Italic 500, размер до 560px, opacity 0.07. Цифра обрезается правым краем viewport. Под ней — четырёхстрочная подпись мелким моноширинным uppercase, объясняющая что это: 50 лет с 1975 года, когда Мандельброт ввёл слово «фрактал» в книге *Fractal Geometry of Nature*.

2. **Speakers — инициалы хедлайнеров** — крупные двухбуквенные сокращения (МЕ, ГТ, МГ, АР, АС, ПТ, НТ) Cormorant 400, opacity 0.05, лежат под именем как водяной знак.

Этот приём — типографика-как-объект — нужен чтобы экран не казался плоским «текстом на фоне». Цифра/инициалы создают визуальную глубину одним только шрифтовым размером, без иллюстраций или фотографий.

### Правила композиции шрифтов

1. **Не больше двух шрифтов на странице.** Cormorant + JetBrains. Не добавлять третий.
2. **Курсив — только display.** В body text курсив не используется ни для эмфазы, ни для цитат.
3. **Uppercase — только labels и кнопки** (мелкие подписи). Заголовки — всегда mixed case Italic.
4. **Letter-spacing для uppercase** обязателен (минимум 0.1em, обычно 0.15-0.22em). Без него uppercase читается как крик.
5. **Number / digit — Cormorant.** Числа в датах («23 мая»), watermark «50», порядковые номера — Cormorant, не JetBrains. Это даёт элегантность.
6. **Не больше 3 разных font weight'ов на странице.** Сейчас: Cormorant 500/700, JetBrains 400. Самый раз.

### Альтернативы (если Claude Design захочет попробовать)

Из исследования 37 шрифтов для постера, для лендинга могут подойти:

- **Papamarkou** (Nikos Giuris) — настоящая греческая angularity (треугольные acutes Φ Α Λ). Лицензия OFL, mutno.me. Self-host, не Google Fonts. Использовать только как замену Cormorant на 1-2 крупных заголовках, не везде.
- **Philosopher** (Jovanny Lemonad) — humanist classical, Google Fonts, кириллица. Альтернатива Cormorant если хочется более «греческого».
- **Piazzolla** (type.today) — transitional serif, многовесовой, бесплатный. Альтернатива для body.

**Чего точно НЕ использовать:**
- ❌ Ruslan Display, Tsarevich, Bardo, Runa, Beryozki — славянский/скандинавский характер, конфликт с греко-античной концепцией
- ❌ Caesar Dressing — handmade angular, читается как «гирос на рекламе кофейни»
- ❌ Inter / Roboto / Arial / системные sans — лишены характера
- ❌ Cinzel / Marcellus / Italiana — нет кириллицы

## Layout — шесть экранов плюс футер

Сайт устроен как последовательность 100vh секций со smooth scroll (без snap):

1. **Preloader** — затемнённый, ~3.6 сек
2. **Hero** — тёмный, заголовок + манифест-зачин + кнопки
3. **Manifest / About** — кремовый, манифест + watermark «50»
4. **Программа / Tracks** — тёмный, Аполлониева упаковка (canvas)
5. **Действующие лица / Speakers** — тёмный, плитка 4×2
6. **Расписание / Schedule** — папоротник на весь экран (iframe)
7. **CTA** — амбер во всю секцию, две cream-карточки (TimePad + карта)

После CTA — футер: marquee, шесть карточек партнёров, копирайт.

Принцип чередования: dark → light → dark → dark → dark → amber → dark. Тёмное — основа, светлое — пауза внимания, амбер — финальный акцент.

## Card system

Карточки появляются в трёх местах с разными правилами:

### 1. Speakers — карточки на тёмном фоне

8 квадратных карточек в плитке 4×2.

- Фон — `--color-surface` (`#1F1B14`), на полтона светлее основного `--color-bg-dark`
- Без рамки (отделяются от фона цветом)
- Скругление 4px max
- Имя курсивом сверху, роль амбером (мелкий капс) под именем
- Огромные инициалы как watermark внутри карточки (opacity 0.05)
- Hover — снизу появляется bio с тёмным градиентом, имя и роль остаются

### 2. CTA — cream-карточки на амбер-фоне

Две большие карточки рядом, в одной строке.

- Фон — `--color-bg-light` (`#ECE3D0`), цвет страницы
- **Тонкая чёрная рамка** `1px solid rgba(22, 20, 15, 0.85)` — обязательно, чтобы карточки читались на амбер-фоне как объекты
- Лёгкая тень `0 6px 20px rgba(22, 20, 15, 0.18)` для глубины
- Скругление 4px
- Высота min 380px / max 440px (близко к квадрату)
- Компактный header сверху ~50px: лейбл (мелкий капс) + название (italic 500)
- Под header — содержимое (виджет TimePad / Яндекс-карта) занимает всё оставшееся место
- При переполнении — скролл внутри карточки со стилизованным `webkit-scrollbar`

Этот тип карточек — самый важный визуально на финальном экране. Cream-on-amber работает как «карточки лежат на освещённом столе».

### 3. Footer — карточки партнёров на тёмном

Шесть карточек в сетке `repeat(6, 1fr)` (на узких — 3×2 или 2×3).

- Фон — `--color-surface`
- Тонкая рамка amber `1px solid rgba(200, 154, 61, 0.18)`
- Скругление 4px
- Имя партнёра курсивом, роль (одна строка) мелким моноширинным под именем
- Hover — рамка становится ярче, лёгкое поднятие на 1-2px

### Чего не делают карточки

- Стандартные SaaS-карточки с border-radius 12, glassmorphism, drop-shadow blur
- Большие иконки сверху
- Тёмные карточки на тёмном фоне без рамки или цветового отделения
- Cream-карточки на cream-фоне без существенной рамки

## Motion

Медленно, как смена света в комнате.

**Используем:**
- **Lenis** для smooth scroll (без snap — мелкие движения тачпада на snap воспринимались как «остановка» и пользователя дёргало)
- **IntersectionObserver + GSAP** — opacity-only reveal (никакого translateY/scale)
- Карточки появляются последовательно с микро-stagger (60-180мс)
- Hover на карточках — тёплая amber подсветка
- Папоротник анимируется при загрузке (рисуется точечно, IFS итеративная отрисовка)
- Аполлониева упаковка раскрывается при прокрутке секции в три этапа
- Прелоудер: letter-by-letter появление title с задержкой по 60мс
- Marquee — медленная горизонтальная прокрутка, ~30 сек на полный круг

**Избегаем:**
- ScrollTrigger (используем IntersectionObserver — проще и предсказуемее)
- translateY/scale в reveal-анимациях
- Snap-навигация по секциям
- Параллакс ради параллакса
- WebGL game-feel
- Постоянное движение фона

## Адаптивность

Сайт спроектирован под десктоп. На мобильном (≤ 600px) — точечные правки чтобы не ломалось:

- Hero: размер заголовка `clamp(40px, 11vw, 64px)`
- About: водяной знак «50» скрыт
- Speakers: одна колонка (требует доработки внутренних max-width)
- Schedule: iframe-папоротник скрыт, fallback-сообщение приглашает открыть с компьютера
- CTA: карточки в одну колонку
- FAQ: одна колонка вместо трёх

В работе с Claude Design мобильный layout — отдельная статья (см. `CLAUDE-DESIGN-BRIEF.md`). Базовое правило: **сайт на мобильном должен сохранять читаемость и не предлагать пользователю того, что на маленьком экране заведомо не работает (Аполлоневу развёртку, пап-ротник Барнсли — лучше сразу вежливо перенаправить на десктоп).**

# Часть II. Anti-patterns — 8 жёстких отказов

Если результат напоминает что-то из этого — переделывать без обсуждения:

1. **Чёрный + ярко-красный** как основная палитра
2. **Холодное неоновое свечение** любого цвета
3. **SaaS-минимализм** в духе Linear / Stripe / Vercel
4. **Брутализм 2020-х** — массивная типографика без warmth
5. **Rave / dance flyer** эстетика
6. **Generic SaaS rounded карточки**
7. **Crowd-фотографии** как эмоциональный слой
8. **Стандартный музейный newspaper-layout**

Дополнительно:
- Не делать «декоративный фрактал» — фрактал должен быть математически точным или его не должно быть
- Не сжимать манифест до слогана
- Не использовать чисто чёрный фон или чисто белые карточки
- Не делать перевод на английский — сайт русский, контент русский

# Часть IV. Reference hunting checklist

Для каждого нового референса — четыре слоя:

1. **Палитра** — какие 3-5 цветов, тёплые или холодные?
2. **Типография** — display/body пара, есть ли кириллица?
3. **Плотность** — сколько воздуха, длины строк?
4. **Атмосфера** — что чувствую через 5 секунд?
