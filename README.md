Снимок сайта фестиваля «Фрактальная Одиссея» на 03.05.2026 и полная документация к нему, собранные для передачи в Claude Design. Задача из брифа: поднять сайт до уровня «7/10», добавить анимацию Аполлониевой развёртки в программе и мобильную версию. Это исходник решений о том, каким должен быть фестиваль и его сайт, а не работающий сайт.

`01-CONCEPT.md` — эмоциональное ядро («интеллектуальный салон в подвале»), аудитория, тон, каким фестиваль быть не должен, и архитектура сайта из шести экранов. `02-DESIGN-SYSTEM.md` — палитра, типографика, три типа карточек, движение, восемь жёстких запретов и референсы. `03-CONTENT.md` — программа по слотам с 14:00 до 04:00, действующие лица, партнёры, финальные тексты сайта, состав Аполлониевой упаковки из 18 кругов. Ещё задание и стартовый промпт для дизайнера, сайт одним файлом `index.html` и архив из 44 отобранных референсов.

Адресат — дизайнер, который продолжает работу прямо в `index.html`; пакет передавался ему целиком. Тексты написаны вручную в Markdown, сайт — HTML с инлайн-стилями, папоротник встроен через iframe, TimePad и Яндекс-карты подгружаются со стороны.

Репозиторий прожил один день: уже 04.05 пошли коммиты в `matema-fest`, куда сайт и переехал. Лекций здесь нет: три дневные лекции (Гельфанд, Райгородский, Скрипченко) — только строки программы, а их слайды лежат в `matema-fest/lectures/`.

Сюда идти за концепцией фестиваля в словах (кадр, аудитория, тон, запреты), за дизайн-системой и за образцом брифа «передать сайт в дизайн». Связи: `matema-fest` (сайт, выросший из этого снимка), `matema-fest-opencall` (приём заявок того же фестиваля) и `gallery`.

# Matema-фест 2026 — Фрактальная Одиссея

Лендинг для авторского интеллектуального фестиваля о красоте математики (23 мая 2026, Москва). Готовая single-file версия сайта + полная документация для передачи в Claude Design.

## Структура

- **`index.html`** — текущий сайт single-file (~165 КБ). Codebase для построения дизайн-системы. Все правки делаются прямо в нём.
- **`CLAUDE-DESIGN-BRIEF.md`** — главный документ для Claude Design. Задачи, требования, ограничения, anti-patterns. Прочитать первым.
- **`STARTER-PROMPT.md`** — стартовый промпт для копирования в чат Claude Design.
- **`01-CONCEPT.md`** — концепт, эмоциональное ядро, архитектура 6 экранов, мобильный опыт.
- **`02-DESIGN-SYSTEM.md`** — палитра, типографика, три типа карточек, motion, референсы.
- **`03-CONTENT.md`** — программа фестиваля, имена, тексты, состав Аполлониевой упаковки (18 кругов), FAQ.
- **`fractal_odyssey_screenshots.zip`** — 44 ручно отобранных референса по категориям A/B/C/D + counterpoint.
