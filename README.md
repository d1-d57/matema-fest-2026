# Matema-фест 2026 — Фрактальная Одиссея

Лендинг для авторского интеллектуального фестиваля о красоте математики (23 мая 2026, Москва). Готовая single-file версия сайта + полная документация для передачи в Claude Design.

## Структура

- **`index.html`** — текущий сайт single-file (~165 КБ). Codebase для построения дизайн-системы. Все правки делаются прямо в нём.
- **`CLAUDE-DESIGN-BRIEF.md`** — главный документ для Claude Design. Задачи, требования, ограничения, anti-patterns. Прочитать первым.
- **`STARTER-PROMPT.md`** — стартовый промпт для копирования в чат Claude Design.
- **`01-CONCEPT.md`** — концепт, эмоциональное ядро, архитектура 6 экранов, мобильный опыт.
- **`02-DESIGN-SYSTEM.md`** — палитра, типографика, три типа карточек, motion, референсы.
- **`03-CONTENT.md`** — программа фестиваля, имена, тексты, состав Аполлониевой упаковки (18 кругов), FAQ.
- **`fractal_odyssey_screenshots.zip`** — 44 ручно отобранных референса по категориям A/B/C/D + counterpoint.
